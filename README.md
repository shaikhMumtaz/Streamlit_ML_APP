# 🌱 Dry Bean Classification Using Machine Learning

A multiclass classification project that trains and compares five machine learning algorithms on the UCI Dry Bean dataset and presents results through an interactive Streamlit application.

## 1. Problem statement
Predict the variety of a dry bean from its physical measurements. The project compares Logistic Regression, Decision Tree, K-Nearest Neighbors, Gaussian Naive Bayes, and Support Vector Machine.

## 2. Dataset description
- **Dataset:** Dry Bean Dataset
- **Source:** UCI Machine Learning Repository
- **Official page:** https://archive.ics.uci.edu/dataset/602/dry+bean+dataset
- **Features:** 16 numerical measurements
- **Target:** `Class`
- **Classes:** Seker, Barbunya, Bombay, Cali, Dermason, Horoz, Sira
- **Problem:** Multiclass classification

Download `Dry_Bean_Dataset.xlsx` from the UCI page and place it in the project root before training. The training script also accepts `Dry_Bean_Dataset.csv`.

## 4. Run locally or in BITS Virtual Lab

### Install dependencies
```bash
python -m pip install -r requirements.txt
```

### Train and evaluate all five models
```bash
python train_models.py
```

This creates the five saved model pipelines, a labelled `test_data.csv`, and a metrics table. The split is stratified (80% train / 20% test) with random state 42. Precision, recall and F1 use macro averaging; multiclass AUC uses one-vs-rest macro averaging.

### Start Streamlit
```bash
streamlit run app.py
```

Open the local URL printed in the terminal. Upload the generated `test_data.csv` to view predictions, six metrics, a confusion matrix and a classification report.
